# Game Music — página do card

Branch publicado pelo GitHub Pages em https://suricatus.github.io/game-music/.

Cada música tem uma página em `/{artista}/{música}/`, aberta pelo QR code do totem. A página mostra o card no formato Stories, o botão de compartilhar do celular, o download da imagem e os links para ouvir a música.

Os arquivos são gerados pela Unity, no projeto Game Music: **Game Music > Card > Exportar página do card…**. Não edite à mão: exporte de novo e substitua a pasta do artista.
